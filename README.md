# Image-Denoising
A comparative image denoising project using the BSD500 dataset and three CNN autoencodedr architectures: Shallow AE, Deep AE, and Resiual AE. Images are corrupted with mixed Gaussian, Salt-and-Pepper, and Speckle noise and denoised using MSE and hybrid MSE–SSIM loss. Models are evaluated using PSNR and SSIM metrics.
